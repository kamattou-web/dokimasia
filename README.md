# Dokimasia

Préparer un concours de la fonction publique : ce que les jurys attendent d’après leurs rapports officiels, le langage du métier, des cours, des quiz et des dilemmes professionnels corrigés, pour 52 concours.

Application web installable (Mac, Windows, tablette), utilisable sans connexion une fois installée. La progression reste sur l’ordinateur de chaque utilisateur.

Ouvrir : https://kamattou-web.github.io/dokimasia/
